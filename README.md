# SMASH 충남대 (선물용)

충남대 캠퍼스를 3D로 부수는 시험기간 스트레스 해소 게임입니다. (충남대학교와 무관한 비공식 팬 게임)

## 이번 버전에서 달라진 점
- **건물이 구분됩니다**: 이름·용도로 외벽 스타일(석재·벽돌·유리·콘크리트·금속 패널 등)을 정하고, 창문·층 구분·창틀·기단·처마를 셰이더로 그립니다. 윤곽선으로 형태가 또렷합니다.
- **건물 이름 라벨**: 화면에 건물 이름이 뜹니다(가까운 것부터, 겹치지 않게). 🏷️ 버튼 / L 키로 끄고 켭니다. PC에서는 마우스를 올리면 이름이 보입니다.
- **랜드마크 강조**: 정문(교문 3D 모델 + 학교명 간판), 백마상, 정심화국제문화회관·중앙도서관·대학본부 등 주요 건물에 금색 라벨·옥상 간판·바닥 하이라이트 링이 붙습니다. 📍 버튼 / G 키로 **랜드마크 투어**(정문 → 백마상 → 주요 건물). 랜드마크를 무너뜨리면 +300 보너스, 결과 카드에 "⭐ 랜드마크 n/m"이 표시됩니다.
- **지면이 지도처럼**: 도로(차선·인도), 잔디, 숲, 운동장(트랙), 연못, 주차장을 바닥 텍스처로 그립니다. 나무도 심어집니다(폭발하면 쓰러짐).
- **모바일 최적화**: 작은 화면용 HUD, 저사양 모드(`?lite=1`), 그림자·텍스처 자동 축소.
- 시점 버튼: 🗺️ 위에서 보기(T) · 🏠 처음 시점(H). 숫자키 1~6 무기, N 밤.

## 올리는 법 (GitHub Pages)
1. GitHub에서 새 저장소(예: `SMASH-CNU`)를 만들고 이 폴더의 파일을 그대로 올립니다.
   - 필요한 것: `index.html`, `src/`, `vendor/` (강력 추천: `campus.json`)
2. 저장소 **Settings → Pages → Branch: main / (root)** 로 켭니다.
3. `https://<내아이디>.github.io/SMASH-CNU/` 링크를 선물하면 끝!

## 받는 사람 이름·메시지 넣기
링크 뒤에 붙이면 인트로 화면에 표시됩니다.
`https://<내아이디>.github.io/SMASH-CNU/?to=민지&msg=시험기간%20화이팅`

## 지도 데이터 (중요)
- 기본: 열릴 때 OpenStreetMap에서 충남대 건물·도로·녹지·교문을 자동으로 불러옵니다(한 번 받으면 브라우저에 저장).
- 불러오지 못하면 내장 근사 캠퍼스로 자동 전환됩니다(실제 지도 아님).
- **추천**: 인터넷 되는 PC에서 `python3 tools/fetch_campus.py` → 생성된 `campus.json`을 `index.html` 옆에 두고 함께 올리세요. 받는 사람 폰에서 훨씬 빠르고 안정적입니다.
- 실행 결과에 "건물 N동(이름 M)"이 찍힙니다. **이름이 없는 건물은 라벨이 안 뜹니다.** OSM(openstreetmap.org)에서 해당 건물의 `name`을 보태면 다음 fetch부터 반영됩니다. 정문 노드가 OSM에 없으면 게임이 캠퍼스 동쪽(대학로 방향) 경계에 정문을 자동 배치합니다.

### 랜드마크 규칙 바꾸기
`src/landmarks.js`의 `LANDMARKS` 배열에 `[이름 정규식, 아이콘, 표시 이름, 한 줄 설명, 우선순위]`를 추가·수정하면 됩니다. 건물 스타일 규칙은 `src/geo.js`의 `RULES`에 있습니다.

## 조작
탭 = 공격 · 드래그 = 회전 · 두 손가락 = 확대/이동 (PC: 휠 확대, 오른쪽 드래그 이동)
키보드: 1~6 무기 · L 이름 · T 위에서 · H 처음 시점 · N 밤 · G 랜드마크 투어
